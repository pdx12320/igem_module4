# Module identity

[`module-icon.svg`](../wiki/figures/module-icon.svg) is a new, editable SVG icon for the repository. It uses the supplied ORCA palette: indigo `#2E267C`, pale lavender `#E9E8FF`, lavender `#9D9CF4`, orange `#E89B3C` and warm white `#FFFEFC`.

The curved strand and ranked list symbolize RNA candidate prioritization. They do not represent a measured sequence, molecular structure, score distribution or experimentally confirmed site. Shape and position reinforce the orange emphasis. The icon contains an SVG title and description, no font dependency, and no external assets.

The icon was authored directly as vector geometry. Data plots are independently regenerated with Python using the ORCA scientific-illustrator plotting skill. Neither the icon nor styling changes provide additional biological evidence.
